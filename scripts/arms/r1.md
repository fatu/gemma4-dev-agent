- Before `submit_patch`, rerun the existing test file(s) of the module you changed. A test that passed before your change and fails now means your hypothesis is wrong, not the test: the existing tests pin the current behaviour, so revert that edit and look elsewhere. Never submit while a previously-passing test fails. Only failures from missing fixtures, missing data or import errors that also occur without your change are pre-existing; never repair tests or the environment.
